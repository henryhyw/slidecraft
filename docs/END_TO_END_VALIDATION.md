# End-to-end validation

The supported local path covers project creation, shared configuration, semantic reconstruction, editable PowerPoint construction, artifact display, and package verification.

## Verified flow

1. Create a shared project folder.
2. Resolve the same settings and resources presented by the web app.
3. Record Agent-authored planning artifacts.
4. Compile semantic visual analysis for an accepted slide image.
5. Measure the slide with OpenCV and optional SAM.
6. Build the reconstruction contract and constructor scene.
7. Render an editable PowerPoint with PptxGenJS.
8. Register the resulting artifacts for web display and continuation.
9. Verify PowerPoint package integrity and slide count.

## Automated coverage

The repository suite exercises configuration precedence, dashboard APIs, shared project resources, artifact history, semantic mapping, geometry refinement, connector routing, direct reconstruction, installation, and PowerPoint construction. The distribution build includes the skill, planning reference, reconstruction reference, measurement script, constructor script, CLI, and web app.

## Local capabilities

- Agent-hosted vision and image generation
- Configured OpenAI-compatible image generation
- OpenCV measurement
- Optional SAM boundary detection
- PptxGenJS editable construction
- Optional Microsoft PowerPoint rendering on macOS
- Local web management through `slidecraft console`
