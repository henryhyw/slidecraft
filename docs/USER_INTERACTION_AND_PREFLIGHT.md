# Collaborative planning and generation preparation

## Start with the audience

The Agent begins by understanding who will use the deck, what they currently believe, what they should understand afterward, and which decision or action the presentation should enable.

Questions are valuable when their answers could change the governing message, evidence standard, scope, storyline, or audience decision. The Agent explains its assumptions when it can proceed confidently.

## Discuss the research and brief

For collaborative work, the Agent shares these elements before slide generation.

- Source and research synthesis
- Audience transformation
- Governing answer
- Recommended slide count
- Storyline phases
- One conclusion-led message for every slide
- Evidence allocation
- Material assumptions and exclusions

The discussion focuses on whether the proposed deck is worth building and whether each slide advances the audience journey.

When the user delegates execution, the Agent performs the same reasoning and continues through construction.

## Prepare each slide

Each slide receives a communication contract with its audience question, message, evidence, consequence, visual job, and transition. The Agent then selects the construction approach.

- Image generation for information-rich composition
- Native layout for structural pages
- Direct PowerPoint objects for straightforward arrangements

The generation brief includes exact text and data, semantic relationships, relevant assets, selected visual inspiration, and the resolved deck design.

## Use project assets intentionally

Project visuals live under `assets/` and retain their identity, semantic role, and intended use. The Agent assigns them to slides where they strengthen the message. Reusable icons, components, and visual references come from the shared project resource selections.

The web app and Agent use the same resource records, so changes made in either surface reach the next planning or generation decision.

## Review before reconstruction

The Agent inspects the generated candidate for message fidelity, evidence accuracy, visual hierarchy, grouping, connector meaning, legibility, and deck-style coherence. The selected image and its semantic visual analysis then become the inputs to editable reconstruction.
