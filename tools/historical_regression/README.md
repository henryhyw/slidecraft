# Architecture-slide prototype utilities

These scripts preserve the original single-slide experiments used to develop the current package capabilities. They are useful for regression analysis and historical reproduction. New integrations should use `slidecraft` commands or Agent capabilities from `src/slidecraft/`.

The live architecture project and its generated files are stored under `workspace/projects/ai-slide-drafting-architecture/` during local development. That workspace is excluded from Git.

Scripts in this directory expect their inputs and output paths to be supplied explicitly when used outside the original prototype workspace.
